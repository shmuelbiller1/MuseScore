Personal Voice Choir Studio experimental · offline

Start with one singing recording and a MIDI export of your score. Sing one written part alone, layer that melody in unison, or select any combination of one to four independently written choir parts. Tag a recording slice to each note, hear it before and after stretch/pitch correction, and explicitly change a note or transpose the arrangement. Written MIDI and original audio remain unchanged. This offline experiment does not synthesize lyrics or claim realistic voices; wide shifts may sound unnatural.

1 · Source recordings

No recordings loaded. Sing a clear held vowel or import a WAV singing take. For takes over 1.2 seconds, a steady vowel in the first 8 seconds is selected automatically; enter a start/end crop for any part to override it. The tool repeats that vowel on score notes—it cannot carry every word or consonant from the take. Originals are never overwritten or uploaded.

2 · Score timing

Export MIDI from the open score, then select it here. A single note-bearing track can feed a written-part solo; distinct tracks are needed only for the parts you include together. No manuscript recognition or Hebrew text processing.

Pitch correction at 100% targets written pitch; lowering it intentionally relaxes that guarantee.

4 · Optional: tag a sung take to the written notes

For a recording of a sung phrase, mark which source time range belongs to each written note. Drag across the waveform to set the selected note's range, or enter start/end seconds and move it ±50 ms. The score still supplies note pitch, onset, length and rests. The source range is fitted to that note's duration; the center is pitch-shifted while short original attack/release portions remain. This is experimental: it cannot identify syllables automatically and may distort consonants, vowels or extreme bass/treble shifts.

Pitch control: the original MIDI stays unchanged. Choose keys of the same mode for a global transposition (A minor → G minor is −2 semitones), then optionally change any output note individually below. Switching Major ↔ Minor is not a simple transposition; edit the written harmony in MuseScore first. The target key is also a note-choice guide, not an automatic reharmonizer.

5 · Save, listen and export

Session includes the original recording bytes, MIDI score, note tags and voice settings. It stays on your device; save it before closing this page. Processed audio is saved separately as WAV.
