1 · Source recordings

No recordings loaded. Sing a clear held vowel or import a WAV singing take. For takes over 1.2 seconds, a steady vowel in the first 8 seconds is selected automatically; enter a start/end crop for any part to override it. The tool repeats that vowel on score notes—it cannot carry every word or consonant from the take. Originals are never overwritten or uploaded.

2 · Score timing

Export MIDI from the open score, then select it here. A single written-note track is enough for solo or unison; four distinct tracks are required for SATB harmony. No manuscript recognition or Hebrew text processing.

3 · Choose the arrangement

SATB requires four different score tracks. Each can use the same recorded voice, but every part follows its own written notes and rests.

Set each part's source, character and volume below. In SATB mode map four different tracks or use the one-click shared-source button; in solo/unison modes the melody and shared recording above take precedence. Pitch correction at 100% targets written pitch; lowering it intentionally relaxes that guarantee.

4 · Optional: tag a sung take to the written notes

For a recording of a sung phrase, mark which source time range belongs to each written note. Drag across the waveform to set the selected note's range, or enter start/end seconds and move it ±50 ms. The score still supplies note pitch, onset, length and rests. The source range is fitted to that note's duration; the center is pitch-shifted while short original attack/release portions remain. This is experimental: it cannot identify syllables automatically and may distort consonants, vowels or extreme bass/treble shifts.

Load a MIDI and a recording, then choose a part. Guessed ranges are only a starting point; check each by listening.

Click a note row to select it; drag across the waveform to set that note's source range. Adjust the zoom above for precise tags.

All written notes of every active part must have a valid tag in this mode. In unison, all four characters share the same tagged melody; in SATB, tag each independent part. A note's original recording remains available unchanged.

5 · Save, listen and export

Session includes the original recording bytes, MIDI score, note tags and voice settings. It stays on your device; save it before closing this page. Processed audio is saved separately as WAV.

To compare instantly, use Play original or Play processed above. Solo/mute and rerender to inspect one part. The original source and processed mix remain separate.
