# Licensed human-singer demonstration recordings

The eight `a` vowel clips in this directory derive from **VocalSet 1.2**, Wilkins, J., Seetharaman, P., Wahl, A., and Pardo, B. (2018), *VocalSet: A Singing Voice Dataset*, Proceedings of ISMIR 2018, https://zenodo.org/records/1442513 (DOI: 10.5281/zenodo.1442513). The [primary metadata](https://zenodo.org/api/records/1442513) specifies **Creative Commons Attribution 4.0 International** (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/. The included clips are **modified**, not the original full-length VocalSet recordings. CC BY 4.0 is an audio-content licence; it does not license the MuseScore source code, and MuseScore's GPLv3 source code does not license VocalSet.

The four 80 ms, 44.1 kHz mono, 16-bit clips (`*-a.wav`) were produced by Matt Blackman in [Vowel Voice Banks — VocalSet](https://github.com/mblackman/vocalset-vowel-voicebanks): cut from steady-state long tones, 3 ms faded and peak-normalized. That repository's [LICENSE](https://github.com/mblackman/vocalset-vowel-voicebanks/blob/main/LICENSE) identifies the recordings as CC BY 4.0 and its [provenance](https://github.com/mblackman/vocalset-vowel-voicebanks/blob/main/source/ATTRIBUTION.md) traces them to VocalSet. We reproduce those short processed clips unchanged. `after-vocalset-soprano-A4.wav` and `four-part-real-vowel-mix.wav` are *further modified* with this GPLv3 offline renderer at 24 kHz. Attribution to both VocalSet and Matt Blackman applies to these short processed clips and their derivatives.

The four **0.8 second** excerpts (`*-long-a.wav`) were additionally cut by this project from the `source/vocalset/{singer}_long_straight_a.wav` files in the same repository. Their crop offsets are listed below and in [`extract-long.py`](../extract-long.py); each was given a 5 ms fade and normalized to a 0.7 peak. The `after-long-soprano-A4.wav`, `four-part-long-vowel-mix.wav`, `after-tagged-real-tenor.wav`, `after-tagged-A4-to-B4.wav` and `after-tagged-A-minor-to-G-minor.wav` outputs are further transformed at 24 kHz. The self-contained `tagged-real-tenor.choir.json` embeds the exact `tenor-m2-long-a.wav` original clip and score-note tags, so redistribution of that session carries the same CC BY 4.0 attribution obligation. These longer source excerpts trace **directly** to the VocalSet original files; credit VocalSet, and credit Matt Blackman for the source subset/distribution. The extraction script uses only standard Python and local WAVs; the app never downloads any data.

The role labels name the **source singers**, not a guaranteed character of the output. A professionally sung soprano vowel is not proof of a light youthful, non-operatic timbre. The **short** alto demo requires an extreme pitch shift and emits a warning; the longer demo uses a closer source register and its own deep bass note (`../four-independent-real-registers.mid`). None of these tiny vowels demonstrates phrases, lyrics, articulations or a convincing choir. The F0 errors in `../real-vowel-metrics.json` and `../long-vowel-metrics.json` are **not** perceptual realism scores. No licence or permission is inferred for *other* singers, recordings or models.
